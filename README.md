# 🧂 Spice Calc

Калькулятор специй для рецептов. Позволяет создавать рецепты с ингредиентами
и рассчитывать нужное количество специй под любой вес мяса.

## 🔗 Демо
[Открыть приложение](https://aliveagain3228.github.io/ForWork/)

## 🛠 Стек
- React 19
- React Router 7
- SCSS
- Framer Motion
- Vite

## ⚙️ Запуск локально
npm install
npm run dev
